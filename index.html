一、 光栅方程与小角近似

超声波在液体中形成疏密相间的驻波，相当于一个相位光栅。根据光栅方程：

d · sinθ = kλ

其中，d 即为超声波长 λs，k 为衍射级次。由于衍射角 θ 极小，满足近似条件 sinθ ≈ tanθ = (Δx/2) / L。代入上式得到：

二、 线性化模型构建

将近似条件代入并移项，构建光斑间距 Δx 与光屏距离 L 的线性方程：

Δx = ( 2kλ / λs ) · L + b

此式表明，二者应呈严格的线性关系。利用程序对实验数据进行最小二乘法拟合，求出斜率 m = 2kλ / λs。

三、 声速反推计算

根据拟合得到的斜率 m，求得超声波长 λs = 2kλ / m。再结合信号源频率 v，最终求得液体声速：

u = λs · v
